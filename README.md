# 透過ルビジェネレーター（GitHub Pages版）

Astraが出力した `blocks` JSON をブラウザで読み込み、
ルビ付き本文ブロックを **透過PNG** または **カードPNG** に書き出す静的Webアプリです。

## 主な機能
- JSON貼り付け / JSONファイル読込
- ルビ付き本文ブロックのプレビュー
- 各ブロックごとの出力設定
  - 縦横比: 自動 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 / A横 / A縦
  - 配置: 左上 / 上中央 / 左中央 / 中央 / 左下 / 下中央
  - 余白: 小 / 中 / 大
- 透過PNG / カードPNG の個別保存
- 一括保存（全PNGを1つのZIPにまとめて保存）
- おすすめ設定の自動適用
- 文字サイズ / 行間 / 文字色の調整
- ブラウザ内ローカル保存

## JSONの想定形式
```json
{
  "blocks": [
    {
      "id": "p1_lead",
      "page": 1,
      "section": "導入",
      "type": "lead",
      "title": "はじめに",
      "style": "lead_box",
      "content": [
        {"text": "10", "ruby": null},
        {"text": "月", "ruby": "がつ"}
      ],
      "export_preset": {
        "aspect_ratio": "4:3",
        "align": "top-left",
        "padding": "medium"
      }
    }
  ]
}
```

`export_preset` は任意です。入っていない場合は、ブロックタイプごとにおすすめ値を自動設定します。

## GitHub Pages で公開する方法
1. 空のリポジトリを作成
2. このフォルダの中身をそのまま配置
3. Settings → Pages → Deploy from a branch → `main` / `(root)`
4. 公開URLで利用

## 補足
- すべてブラウザ内で処理され、入力JSONはサーバーへ送信されません。
- 透過PNGは、固定縦横比の透明キャンバス上に文章ブロックを配置して出力できます。


## v3の改善
- 縦横比・配置・余白はプレビューにもリアルタイム反映します。
- 一括保存はPNGを個別ダウンロードせず、ZIPを1個だけ保存します。
- Chrome/Edgeでは対応環境なら保存先ダイアログを表示します。
